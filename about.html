TokenDance

菜单栏里的 AI Agent 用量仪表 · 全部数据留在本机
主页 数据源 设置 关于

这是什么

读本机 AI 编程助手（Codex、Claude Code 等）写下的会话转录， 把 token 用量变成能直接看的东西：菜单栏悬浮窗的实时燃烧率、当日总量与命中率，加一份网页仪表盘。

工作原理

应用自带一个本地服务（双击即用，无需安装依赖）：扫描各 agent 的转录目录， 解析每一次调用，存进本机 SQLite，再在本地端口提供数据与网页。

特性

实时悬浮窗
燃烧率里程计、热量变色、每 agent 排行；玻璃质感，跟随系统深浅色。
网页仪表盘
按天 / 数据源 / 项目 / 模型的图表，活动记录热力图，调用记录分页表格。
多数据源
Codex、Claude Code 等自动发现，无需配置。
双击即用
应用自带服务端，自动拉起、崩溃自愈，不依赖开发环境。

隐私

解析、存储、聚合全部发生在本机，token 用量数据不出本机。

默认每 6 小时发一条匿名计数 ping（随机 id、版本号、系统与芯片、界面偏好、 运行时长；不含用量数字、文件名、项目或会话内容），菜单栏可一键关闭，服务端不记录该请求的 IP。 排行榜是另一个开关，默认关闭，参与后才上报当日总量与昵称。

不读取系统隐私目录：通讯录、信息、邮件、Safari、健康、日历、提醒、 iCloud Drive 一律不进入——扫描、按名字搜索、手动填路径三条路都在碰到磁盘之前就拒绝。
